# 🏰 PHP ハノイの塔 ゲーム (Tower of Hanoi)

PHPのセッション管理機能を利用して作られた、ブラウザ上で手軽に遊べるシンプルな「ハノイの塔」パズルゲームです。画面遷移（タイトル、ゲームメイン、クリア、ゲームオーバー）の仕組みを搭載しています。

## 🎮 ゲーム概要

3枚の円盤を、ルールに従って一番左の「棒A」から一番右の「棒C」へとすべて移動させることができればゲームクリアとなります。
ただし、手数が **15手** を超えるとゲームオーバーになります。

### 📋 基本ルール
1. 1回につき1枚の円盤しか移動できません。
2. 棒の一番上にある円盤だけが移動可能です。
3. **小さな円盤の上に、それより大きな円盤を置くことはできません。**

---

## ✨ 主な機能

* **シーン（画面）遷移システム**
  * **タイトル画面**: ゲームの説明と開始ボタンを表示。
  * **ゲーム画面**: 直感的で分かりやすい、円盤のサイズに応じたビジュアル表示。
  * **ゲームクリア画面**: クリア時のかかった手数を祝福とともに表示。
  * **ゲームオーバー画面**: 制限手数を超えた際の終了画面。
* **状態保持 (Session)**: 画面のリロードを行っても、現在のプレイ状態や手数が維持されます。
* **レスポンシブ・シンプルなCSS**: 特別な外部ライブラリを使用せず、標準的なブラウザのみで綺麗に描画されます。

---

## 🛠️ 動作環境

* **PHP**: 7.4 以上（8.x 推奨）
* **ブラウザ**: Google Chrome, Microsoft Edge, Safari, Firefox などの主要ブラウザ
* ※ プレイヤーの状態保持に `session_start()` を使用しているため、ブラウザのCookieが有効である必要があります。

## 🚀 導入・実行方法

1. **ファイルの配置**
   任意のPHP実行環境（Apache、Nginx、またはPHPの組み込みサーバーなど）の公開ディレクトリに、ソースコード（例: `index.php`）を配置します。

2. **ビルトインサーバーでの起動例**
   コマンドラインでファイルがあるディレクトリに移動し、以下のコマンドを実行します。
   ```bash
   php -S localhost:8000
   
ブラウザでアクセス
ブラウザを開き、 http://localhost:8000 にアクセスするとゲームが始まります。

⚙️ カスタマイズについて
ソースコード上部の変数を書き換えることで、難易度を簡単に調整できます。

円盤の数を変更する

PHP
$total_disks = 3; // 4や5に増やすと難易度が上がります（※CSSの調整が必要な場合があります）
制限手数を変更する

PHP
$max_moves = 15; // ゲームオーバーになるまでの猶予手数を変更できます
